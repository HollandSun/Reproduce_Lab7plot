# lab07_betterviz
The original motivation for creating this repository came from a [lab assignment](https://datascience4psych.github.io/DataScience4Psych/lab07.html). In that assignment, we were asked to “make up” a line plot that looked similar to the original figure by visually inspecting the data shown in the figure. I am not entirely sure whether this part of the assignment is still the same, since the course appears to be updated over time.

Since the figure had a clear research context, and I thought if we know where these data came from, why not try to find the actual source? I ended up spending quite a bit of time tracking down the original data source. Eventually, I was able to locate the data and successfully reproduce the figure.

I hope this repository may be useful for others who are interested in the dataset, the original figure, or the process of reproducing published visualizations from source data.

## Kansas COVID-19 Mask Mandate Visualization
This repository reconstructs and examines the a controversial chart

## Data Source
The original chart did not come with a publicly available dataset. However, a subsequent CDC study (Van Dyke et al., 2020) published in MMWR used the same underlying data and cited USAFacts as the source for county-level case and population data. 
The 24 mask-mandate counties were identified from the footnotes of that paper, based on classification by the Kansas Health Institute (KHI).

Cases: https://static.usafacts.org/public/data/covid-19/covid_confirmed_usafacts.csv

Population: https://static.usafacts.org/public/data/covid-19/covid_county_population_usafacts.csv

County classification: Van Dyke et al. (2020), MMWR

## Scripts

#### `prepare_data.R`
Downloads raw county-level COVID-19 case data and population data from USAFacts, filters for Kansas counties from July 5 to August 3, 2020, calculates daily new cases from cumulative counts, and classifies each county as "Mask" or "No Mask" based on the CDC paper. Outputs two CSV files:
- **kansas_case_jul05_aug03_2020.csv** — Raw daily new cases at the county level
- **kansas_grouped_rolling_avg.csv** — Aggregated by mask mandate group with per 100K rates and 7-day rolling averages, ready for plotting

#### `plot_ggplot.R`
Reads the CSV generated by the first script,  calculates per 100K rates and 7-day rolling averages, and produces plot.

## Result
The final replicated figure is saved in the "misleading_plot.png" file and almost perfectly reproduces the original plot presented in Lab 07.
